Terraform, CI/CD and GitOps. I'm also a tech lead who likes sharing knowledge and helping a team grow,

I'm looking for my next challenge on **cloud / DevOps projects** (engineer or architect),

## 🧭 What I've done

- ☁️ **AWS serverless:** TypeScript backend on ~50 Lambda functions, infrastructure managed as code with CDKTF, monitored with CloudWatch.
- ☸️ **Kubernetes & GitOps:** a reusable NestJS microservices blueprint rolled out to several brands with Terraform, on GKE, delivered with FluxCD, observed with Prometheus and Grafana.
- 🐳 **Containers & messaging:** microservices on Docker Compose and Swarm with Kafka / RabbitMQ and GitLab CI, to supervise operating-room data.
- 🤝 **Tech lead:** mentoring juniors, running demos, coordinating a team, working in English every day.
